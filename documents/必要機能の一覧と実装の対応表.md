# 必要機能の一覧と実装の対応表

## A. データの取得と判定（サーバー側）

| 番号 | 必要機能 | 対応する実装 | 備考 |
|---|---|---|---|
| 1 | 千葉市のオープンデータから品目と回収場所を読み込む | `SQL/010_item.sql`、`SQL/011_item_seed.sql`<br>`SQL/020_recycle_location.sql`、`SQL/021_recycle_location_seed.sql` | 出典：千葉市ごみ分別辞典（2,070品目）、千葉市小型家電回収場所一覧 |
| 2 | 捨てたい品目を一覧から見つけられるようにする | `lib/item-search.js` の `filterAndSortItems()`<br>`app.js` の `renderSearchPage()` | |
| 3 | 品目名をうろ覚えでも検索できるようにする | `lib/item-search.js` の `normalizeSearchText()`、`filterAndSortItems()`<br>`app.js` の `getSearchQuery()` | 品目名・読み仮名の部分一致。NFKC 正規化・小文字化・カタカナ→ひらがな変換で表記ゆれを吸収 |
| 4 | 持込が必要かどうかを判定し、必要な場合だけ回収場所を案内する | `app.js` の `renderResultPage()`<br>`lib/site-search.js` の `getRecoveryTypes()`<br>`lib/item-result.js` の `buildItemBadges()` | 回収種別が0件なら地図と一覧を表示しない |
| 5 | その品目を受け入れる回収場所だけを絞り込む | `app.js` の `getItemSites()`<br>`lib/site-search.js` の `getRecoveryTypes()` | `battery` / `phone` / `other_electronics` の該当種別を OR 条件にして検索 |
| 6 | 現在地から近い回収場所が分かるようにする | `lib/site-search.js` の `calculateDistanceKm()`、`roundToThreeDecimals()`、`buildSiteList()` | Haversine 式による直線距離 |
| 7 | 回収場所の利用時間を確認できるようにする | `SQL/020_recycle_location.sql` の `business_hours` 列<br>`app.js` の `getItemSites()`<br>`public/js/result.js` の `createSiteCard()` | 登録された表記をそのまま表示。営業中・時間外の自動判定は行わない |

## B. 画面表示

| 番号 | 必要機能 | 対応する実装 | 備考 |
|---|---|---|---|
| 8 | 品目一覧と検索結果を画面に表示する | `views/index.ejs`<br>`app.js` の `renderSearchPage()` | |
| 9 | 回収場所の位置関係を地図で把握できるようにする | `public/js/map.js` の `createSiteMap()`<br>`views/result.ejs`（Leaflet の読み込み） | Leaflet + OpenStreetMap |
| 10 | 回収場所の詳細を一覧で比較できるようにする | `public/js/result.js` の `createSiteCard()`、`renderLocatedSites()` | |
| 11 | 一覧で選んだ回収場所を地図上で確認できるようにする | `public/js/map.js` の `focusSite()`<br>`public/js/result.js` の `createSiteCard()`、`scrollMapIntoViewIfNeeded()` | 「地図で見る」で地図へスクロールし、対象施設を拡大して吹き出しを開く |
| 12 | 利用者の現在地を取得する | `public/js/result.js` の `getCurrentLocation()`、`start()`<br>`lib/site-search.js` の `parseCoordinates()` | Geolocation API |
| 13 | 回収場所までの経路を調べられるようにする | `public/js/result.js` の `createGoogleMapsLink()` | Google マップを別タブで開く |

## C. 例外時の動作

| 番号 | 必要機能 | 対応する実装 | 備考 |
|---|---|---|---|
| 14 | 位置情報を取得できない場合も、回収場所を探せる状態を維持する | `lib/site-search.js` の `WARD_ORDER`、`buildSiteList()`<br>`public/js/result.js` の `renderGroupedSites()`、`start()` | 距離を表示せず、区を50音順、区内は施設の読み仮名順で表示 |
| 15 | 地図を読み込めない場合も、回収場所の一覧を利用できるようにする | `public/js/map.js` の `showMapFailure()`<br>`public/js/result.js` の `disableMapButtons()`、`showMapForSites()` | |
| 16 | データを取得できない場合、状況を伝えて再試行できるようにする | `app.js` の `renderSearchPage()`、`renderResultPage()`、`getItemSites()`<br>`public/js/result.js` の `loadSites()`、`showFeedback()` | |
| 17 | 該当する品目がない場合、その旨を伝える | `app.js` の `renderSearchPage()`<br>`views/index.ejs` | |
