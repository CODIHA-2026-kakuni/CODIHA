# 必要機能の一覧と実装の対応表

## A. データの取得と判定（サーバー側）

| 番号 | 必要機能 | 対応する実装 | 備考 | 担当 |
|---|---|---|---|---|
| 1 | 品目一覧を読み仮名の50音順で表示する | `Application/lib/item-search.js` の `filterAndSortItems()`<br>`Application/app.js` の `renderSearchPage()` | `Intl.Collator('ja')` で並び替え。`item.reading` を使用し、同順の場合はID昇順 | 梅澤 |
| 2 | 品目名・読み仮名の部分一致で検索する | `Application/lib/item-search.js` の `normalizeSearchText()`、`filterAndSortItems()`<br>`Application/app.js` の `getSearchQuery()` | NFKC正規化・小文字化・カタカナからひらがなへの変換で表記ゆれを吸収。検索語は100文字まで | 梅澤 |
| 3 | 品目の詳細と持込の要否を判定し、要否に応じて表示内容を切り替える | `Application/app.js` の `renderResultPage()`<br>`Application/lib/site-search.js` の `getRecoveryTypes()`<br>`Application/lib/item-result.js` の `buildItemBadges()` | 回収種別が0件なら地図と一覧を出さず `state='empty'`、1件以上なら `state='pending-location'` | 梅澤 |
| 4 | 品目を受け入れる施設を抽出する | `Application/app.js` の `getItemSites()`<br>`Application/lib/site-search.js` の `getRecoveryTypes()` | `battery`、`phone`、`other_electronics` のtrueをOR条件にして `recycle_location` を検索 | 大菅 |
| 5 | 現在地から各施設までの直線距離を計算し、近い順に並べる | `Application/lib/site-search.js` の `calculateDistanceKm()`、`roundToThreeDecimals()`、`buildSiteList()` | Haversine式。地球半径6371km。小数点以下3桁に丸める | 大菅 |
| 6 | データベースに登録された施設の利用時間を表示する | `Application/SQL/020_recycle_location.sql` の `business_hours` 列<br>`Application/app.js` の `getItemSites()`<br>`Application/public/js/result.js` の `createSiteCard()` | 営業中・時間外の自動判定は行わない。未登録時は「情報なし」と表示 | 大菅・梅澤 |
## B. 画面表示

| 番号 | 必要機能 | 対応する実装 | 備考 | 担当 |
|---|---|---|---|---|
| 7 | 品目一覧と検索結果を画面に表示する | `Application/views/index.ejs`<br>`Application/app.js` の `renderSearchPage()` | `state` でsuccess、empty、no-data、error、loadingを切り替え | 梅澤 |
| 8 | 地図を表示する | `Application/public/js/map.js` の `createSiteMap()`<br>`Application/views/result.ejs`（Leafletの読み込み） | Leaflet + OpenStreetMap。施設が0件のときは千葉市役所を中心にズーム11で表示 | 梅澤 |
| 9 | 施設の一覧をカード形式で表示する | `Application/public/js/result.js` の `createSiteCard()`、`renderLocatedSites()` | 順位（位置情報ありの場合）・直線距離・施設名・住所・利用時間 | 梅澤 |
| 10 | 地図マーカーと施設カードを連動させる | `Application/public/js/map.js` の `focusSite()`<br>`Application/public/js/result.js` の `createSiteCard()`、`scrollMapIntoViewIfNeeded()` | 施設カードの「地図で見る」で地図へスクロールし、対象施設をズーム16で表示して吹き出しを開く | 梅澤 |
| 11 | ブラウザから現在地を取得する | `Application/public/js/result.js` の `getCurrentLocation()`、`start()`<br>`Application/lib/site-search.js` の `parseCoordinates()` | Geolocation API。タイムアウト10秒。サーバー側でも緯度・経度の範囲を検証 | 梅澤 |
| 12 | Googleマップの経路検索を別タブで開く | `Application/public/js/result.js` の `createGoogleMapsLink()` | 施設の緯度・経度からURLを生成。`target="_blank"` と `rel="noopener noreferrer"` を付与 | 梅澤 |
## C. 例外時の動作

| 番号 | 必要機能 | 対応する実装 | 備考 | 担当 |
|---|---|---|---|---|
| 13 | 位置情報がない場合、距離を表示せず、施設を区ごとにまとめて表示する | `Application/lib/site-search.js` の `WARD_ORDER`、`buildSiteList()`<br>`Application/public/js/result.js` の `renderGroupedSites()`、`start()` | 区を50音順で表示し、各区の中では施設の読み仮名順に表示する。見出しを「回収場所（区ごと）」に変更し、案内文を表示 | 大菅・梅澤 |
| 14 | 地図を読み込めない場合も、施設一覧の表示を継続する | `Application/public/js/map.js` の `showMapFailure()`<br>`Application/public/js/result.js` の `disableMapButtons()`、`showMapForSites()` | Leaflet未読み込み時も一覧とGoogleマップは利用可能。「地図で見る」ボタンのみ無効化 | 梅澤 |
| 15 | データを取得できない場合、エラーを表示して再読み込みを促す | `Application/app.js` の `renderSearchPage()`、`renderResultPage()`、`getItemSites()`<br>`Application/public/js/result.js` の `loadSites()`、`showFeedback()` | 内部エラー情報は返さず定型文のみ表示。再試行ボタンから再取得できる | 梅澤 |
| 16 | 該当する品目が0件の場合にその旨を表示する | `Application/app.js` の `renderSearchPage()`<br>`Application/views/index.ejs` | 検索結果0件は `state='empty'`、品目データそのものが0件の場合は `state='no-data'` として区別 | 梅澤 |
