# 必要機能の一覧と実装の対応表

## A. データの取得と判定（サーバー側）
 
| 番号 | 必要機能 | 対応する実装 | 備考 | 担当 |
|---|---|---|---|---|
| 1 | 品目一覧を読み仮名の50音順で表示する | `Application/lib/item-search.js`、`Application/app.js` | | 梅澤 |
| 2 | 品目名・読み仮名の部分一致で検索する | `Application/lib/item-search.js`、`Application/app.js` | | 梅澤 |
| 3 | 品目の詳細と持込の要否を判定し、要否に応じて表示内容を切り替える | `Application/lib/item-result.js`、`Application/app.js` | | 梅澤 |
| 4 | 品目を受け入れる施設を抽出する | `Application/app.js`の`getItemSites` | | 大菅 |
| 5 | 現在地から各施設までの直線距離を計算し、近い順に並べる | `Application/lib/site-search.js` | Haversine 式 | 大菅 |
| 6 | データベースに登録された施設の利用時間を表示する | `Application/app.js`、`Application/public/js/result.js` | 営業中・時間外の自動判定は行わない | 大菅・梅澤 |
 
## B. 画面表示
 
| 番号 | 必要機能 | 対応する実装 | 備考 | 担当 |
|---|---|---|---|---|
| 7 | 品目一覧と検索結果を画面に表示する | `Application/views/index.ejs` | | 梅澤 |
| 8 | 地図を表示する | `Application/public/js/map.js` | Leaflet + OpenStreetMap | 梅澤 |
| 9 | 施設の一覧をカード形式で表示する | `Application/public/js/result.js` | 順位（位置情報ありの場合）・直線距離・施設名・住所・利用時間 | 梅澤 |
| 10 | 地図マーカーと施設カードを連動させる | `Application/public/js/result.js`、`Application/public/js/map.js` | 施設カードの「地図で見る」で地図へスクロールし、対象施設をズーム16で表示して吹き出しを開く | 梅澤 |
| 11 | ブラウザから現在地を取得する | `Application/public/js/result.js` | Geolocation API | 梅澤 |
| 12 | Google マップの経路検索を別タブで開く | `Application/public/js/result.js` | | 梅澤 |
 
## C. 例外時の動作
 
| 番号 | 必要機能 | 対応する実装 | 備考 | 担当 |
|---|---|---|---|---|
| 13 | 位置情報がない場合、距離を表示せず、施設を区ごとにまとめて表示する | `Application/lib/site-search.js`、`Application/public/js/result.js` | 区を50音順で表示し、各区の中では施設の読み仮名順に表示する | 大菅・梅澤 |
| 14 | 地図を読み込めない場合も、施設一覧の表示を継続する | `Application/public/js/map.js`、`Application/public/js/result.js` | | 梅澤 |
| 15 | データを取得できない場合、エラーを表示して再読み込みを促す | `Application/app.js`、`Application/views/index.ejs`、`Application/views/result.ejs`、`Application/public/js/result.js` | | 梅澤 |
| 16 | 該当する品目が0件の場合にその旨を表示する | `Application/app.js`、`Application/views/index.ejs` | | 梅澤 |
