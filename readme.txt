CODIHA（千葉市 ごみ分別・持込ナビ）

チームチャンネル名：角煮

提出者：
・梅澤颯太（千葉工業大学 情報工学科）


1. 概要・主要機能

CODIHAは、千葉市のごみ品目の分別方法と、小型家電の回収場所を案内するWebアプリケーションです。

利用者は、MySQLに登録された2,058品目すべてを品目名または読み仮名で検索できます。選択した品目に小型家電の回収区分が設定されている場合は、対応する回収施設と地図を表示します。回収区分が設定されていない品目では、分別区分、出し方、注意事項を表示し、地図と施設一覧は表示しません。

2,058品目のうち89品目には、小型家電の回収区分が設定されています。

主な機能は次のとおりです。

・品目名または読み仮名による部分一致検索
・全角と半角、英字の大文字と小文字、ひらがなとカタカナの違いを吸収した検索
・選択した品目の分別区分、出し方、注意事項の表示
・小型家電の回収対象品目に設定された回収種別の表示
・品目の回収種別に対応する施設の抽出
・ブラウザからの現在地取得
・現在地から回収場所までの直線距離の計算
・位置情報を取得できた場合の、距離が近い順での施設表示
・位置情報を取得できなかった場合の、区ごとおよび施設の読み仮名順での表示
・OpenStreetMapを利用した現在地と回収場所の地図表示
・施設カードの「地図で見る」による地図移動、吹き出し表示、地図へのスクロール
・Googleマップの経路検索を別タブで開く機能
・位置情報、回収場所データ、地図を取得できない場合の案内表示

施設は30件登録されています。施設の利用時間はMySQLに登録された文字列をそのまま表示し、現在営業中かどうかの自動判定は行いません。

位置情報の取得は、回収場所がある品目の結果画面だけで行います。現在地は、対応施設までの直線距離を計算するためだけに使用し、MySQL、ファイル、ログなどへ保存しません。

使用している主なデータは、千葉市のごみ分別情報、小型家電・充電式電池の回収案内、公共施設位置情報を基にしています。

千葉市 小型家電・充電式電池の回収案内
https://www.city.chiba.jp/kankyo/junkan/haikibutsu/kogatakadenn.html

千葉市 ごみ分別ガイド
https://www.city.chiba.jp/kurashi/gomi/gomi/gomiguide/index.html

千葉市 公共施設位置情報
https://www.city.chiba.jp/sogoseisaku/shichokoshitsu/kohokocho/map_opendata.html


2. 使用しているポート番号

・3000/TCP：Webアプリケーションへの接続に使用します。
  接続先は http://localhost:3000 です。

・3306/TCP：ホストOSからMySQLへ直接接続する場合に使用します。
  Webアプリケーションを通常利用するだけの場合、利用者がこのポートへ直接接続する必要はありません。


3. ログイン情報

アプリケーションの利用にログインは不要です。

通常の実行では、利用者がMySQLへ直接ログインする必要はありません。WebコンテナからMySQLコンテナへの接続設定はcompose.yamlに記載しています。


4. 実行方法

前提として、Docker Desktopがインストールされ、起動している必要があります。

1）このreadme.txt、Dockerfile、compose.yamlが存在する作業ディレクトリをターミナルで開きます。

2）次のコマンドを実行します。

docker compose up --build

3）MySQLコンテナの準備とWebコンテナの起動が完了するまで待ちます。初回起動時は、Application/SQL内のSQLとCSVからテーブルと初期データが自動で登録されるため、2回目以降より時間がかかる場合があります。

4）Webブラウザで次のURLを開きます。

http://localhost:3000

5）終了する場合は、起動コマンドを実行したターミナルでControlキーとCキーを同時に押します。その後、必要に応じて次のコマンドでコンテナを停止・削除します。

docker compose down

docker compose downではMySQLのデータを保存するDockerボリュームは削除されません。


特記事項・補足

・OpenStreetMapの地図画像とLeafletをインターネットから読み込むため、地図表示にはインターネット接続が必要です。

・回収場所がある品目では、ブラウザに位置情報の確認が表示されます。現在地から近い順に表示する場合は「許可」を選択してください。

・localhost以外の端末から位置情報を使用する場合は、原則としてHTTPSでの接続が必要です。

・位置情報を許可しない場合や取得できない場合も、回収場所がある品目では施設を区ごとに確認できます。この場合、直線距離と現在地マーカーは表示されません。

・地図を読み込めない場合も、施設一覧とGoogleマップの経路検索は利用できます。

・表示する距離は直線距離です。実際の道路に沿った移動距離や所要時間ではありません。経路は「Googleマップで経路」から確認してください。

・施設の休館日、祝日、臨時休館、現在営業中かどうかは自動判定しません。表示された利用時間を確認し、必要に応じて施設の公式情報も確認してください。

・MySQLのデータをすべて削除して初期状態へ戻す操作は通常の動作確認では不要です。docker compose down -vを実行すると保存済みのMySQLデータが削除されるため、注意してください。
